\bd[Huber ring]
A \textit{Huber ring} is a topological ring $A$ that admits an open subring $A_0 \subs A$ and an ideal $I \subs A^+$, such that there exists some finitely generated $A_0$-ideal $I \subs I$, such that $A_0$ has the $I$-adic topology.

\bd[Ring of integral elements]
A \textit{ring of integral elements} in a Huber ring $A$ is an open, integrally closed subring $A^{+}$ that contains the power-bounded elements.
\begin{align*}
A^{+} \subs A = \{ \text{ power-bounded elements }  \}
\end{align*}
\ed

Finally, a Huber pair is the pair $(A^+, A)$ satisfying these conditions.

\bd[Huber pair]
A \textit{Huber pair} is a pair $(A, A^{+})$, where $A$ is a Huber ring and $A^{+}$ is a ring of integral elements of $A$.
\ed
