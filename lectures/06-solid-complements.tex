\subsection{Recap of previous lecture}

Let's briefly recall the definition. The object $P$ has always denoted the projective object, which, as a free $\Z$-module, is $\Z[\N \cup \infty]$, the nullsequences:
\be
P = \Z[\N \cup \infty] / \Z[\infty].
\ee

Then, we considered this endomorphism $f$ of $P$, which is the identity minus the shift. This map takes the generator $n$ to $[n+1] - [n]$, as shown below:
\begin{align*}
f = \text{id-shift$\cl$ } P \to P
\end{align*}
\begin{align*}
[n] \mapsto [n+1] - [n]
\end{align*}

With this, the new definition of a solid module emerged, which is entirely analogous to the old definition, but applied to $P$-modules.

\bd[Solid]
$M \in \Cond\Ab^\light$ is \textit{solid} if the map induced by $f$ is an isomorphism.
\be
f^\ast \cl \IntHom(P,M) \iso \IntHom(P,M)
\ee

% 2:07
Intuitively speaking, $f$ is a map from $P$ to $M$, the space of nullsequences in $M$. So we take a nullsequence in $M$ and map it to the sequence of differences, as shown below:
\begin{align*}
(m_1, m_2, \ldots) \mapsto (m_0 - m_1, m_1 - m_2, \ldots)
\end{align*}
\ed

This being an isomorphism means that conversely, if we have any nullsequence in $M$, we can reconstruct it by summing the differences. In this way, the first terms $m_0$ must be the sum of all the differences in the sequence.
