\subsection{Recap}

We introduced the category $\Solid_\Z$ of solid abelian groups, which is a full subcategory of light condensed abelian groups:
\begin{align*}
\Solid_\Z \subseteq \Cond_\Z^\light.
\end{align*}

This $\Solid_\Z$ serves as an analog of complete non-archimedean topological abelian groups, but from a formal perspective, it is easier to work with. It is an abelian category that is closed under limits, colimits, extensions, and many other constructions.
% 1:30
Additionally, we introduced the left adjoint $(\ldots)^\solid$, known as solidification. 

\note{todo, equation for left adjoint}

There is a symmetric monoidal structure here, which we can think of as a completed tensor product. The completion functor in this context is symmetric monoidal.

% 1:50
The definition of this structure is based on the object$P$, which is the free module on a nullsequence:
\begin{align*}
P = \Z[\N \cup \infty] / \Z(\infty).
\end{align*}

% 2:00
The definition was that $M$ is considered solid if the map from nullsequences to nullsequences ,given by $\id - \sigma$, is an isomorphism. (Here, $\id - \sigma$ represents a shift on $\N$.)
The condition can be written as:
\begin{align*}
M \text{solid} \iff \IntHom(P,M) \xrightarrow[\iso]{\id - \sigma} \IntHom(P,M).
\end{align*}
